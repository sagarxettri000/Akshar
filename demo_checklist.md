### Known Issues (Non-Blocking):

1. **Tab labels have garbled emojis** - The Streamlit tab labels display incorrectly due to emoji rendering. The tab function call shows `"dY"? Explain"`, `"dY' Ask"`, etc. This is a cosmetic issue in the `st.tabs()` call that uses emoji characters.

2. **AI features require `GOOGLE_API_KEY`** - All AI functionality (Summary, Ask, Practice questions, Flashcards) needs the API key configured via Streamlit secrets or environment variable.

3. **First Gemma 4 call is slow** - Initial response can take 20-40 seconds; subsequent calls are faster.
